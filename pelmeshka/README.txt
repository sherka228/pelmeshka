# Telegram-бот расписания

## 1. Установка

```bash
pip install -r requirements.txt
```

## 2. Токен

Получите токен у @BotFather и задайте переменную:

### Windows PowerShell
```powershell
$env:BOT_TOKEN="123456:ABCDEF..."
```

### macOS / Linux
```bash
export BOT_TOKEN="123456:ABCDEF..."
```

Либо замените `ВСТАВЬ_СЮДА_ТОКЕН_БОТА` в `bot.py`.

## 3. Файлы

Положите рядом:
- `bot.py`
- `requirements.txt`
- `расписание_на_5_неделю_с_28_09_по_02_10_2026_г.xlsx`

## 4. Запуск

```bash
python bot.py
```

## Как работает

1. Пользователь нажимает `/start`.
2. Бот предлагает выбрать курс.
3. Затем предлагает выбрать профиль/группу.
4. Выбор сохраняется в памяти запущенного бота.
5. Кнопка `📅 Сегодня` берёт текущую дату компьютера/сервера.
6. Бот находит эту дату в Excel и отправляет пары, время и аудитории.
7. Если в Excel есть строки с `Примечание`, `Заметка`, `Важно` или `Внимание`, они также выводятся как заметки.

Для постоянного хранения выбора пользователей можно заменить MemoryStorage на Redis.
